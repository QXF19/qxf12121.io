一键安装包

这是一个适用于 Windows x64 的单文件安装程序。它内置四个安装文件：前三项按顺序静默安装，火绒打开安装界面由你手动完成。每项软件都可以跳过；最后的 PowerShell 步骤也可以单独跳过。

交付文件名为 一键安装-可跳过-火绒手动.exe；项目中的打包文件名为 OneClickSetup-SkipOptions.exe。运行整合包时，不需要再把四个原始安装文件放在旁边。

包含的软件

顺序 软件 处理方式
1 7-Zip 26.03 静默安装
2 驱动总裁（9999.exe） 静默安装
3 图吧工具箱 2025.02 静默安装
4 火绒安全软件 6.0.12.1 打开原安装界面，手动安装

使用方法

  1. 双击 一键安装-可跳过-火绒手动.exe，同意 Windows 的管理员权限提示。

  2. 在命令行选择安装范围：

    输入 效果
    直接回车或 A 安装全部四项
    H 安装前三项，跳过火绒
    S 跳过全部四项
    C 自选要跳过的编号，例如 2,4

  3. 单独选择最后的 PowerShell 步骤：直接回车或 Y 表示执行，N 表示跳过。这个选择不影响前面的软件安装范围。

  4. 若选择安装火绒，请在打开的火绒界面中完成安装，再回到原命令行按回车继续。整合包不会自动判断火绒是否已安装完成。

  5. 若选择执行 PowerShell 步骤，程序会打开一个新的 PowerShell 窗口并运行以下命令：

    新窗口会保持打开，供你查看输出。关闭它后，原命令行才会显示最终结果；按任意键关闭原命令行。选择 N 时不会打开这个 PowerShell 窗口。

如果只想检查安装包内置文件、不安装软件也不运行网络命令，可以选择 S，然后选择 N。

进度与日志

  • 命令行会显示当前软件、已用时间和阶段进度。百分比按完成的安装步骤数计算，不代表安装程序内部的真实百分比；安装器长时间没有输出时，耗时仍会继续更新。
  • 开始前会核对四个内置安装文件的 SHA-256，包括你选择跳过的文件。缺失或校验不符时，流程会停止。
  • 某个软件安装程序报错时，整合包会记下错误并继续处理其余步骤，最后报告失败。返回码 3010 表示安装程序请求重启。
  • 日志保存在 %TEMP%\OneClickSetup-日期时间.log。排查问题时，请提供该日志和你选择的安装范围。

PowerShell 步骤说明

该命令会从 get.activated.win 下载并立即执行 Microsoft Activation Scripts。网络脚本不包含在本安装包内，其内容可能变化，也不受上述四个安装文件的 SHA-256 校验覆盖。请确认你信任该来源后再选择 Y；不需要此步骤时选择 N。

项目文件

  • install.ps1：校验、选择菜单、安装流程和日志。
  • launch.cmd：启动 PowerShell 安装脚本，并在结束时保留命令行结果。
  • OneClickSetup.sed：Windows IExpress 的单文件打包配置。
  • OneClickSetup-SkipOptions.exe：构建出的整合安装程序。

已检查打包文件可以解包、内置脚本与项目文件一致，并完成预检。当前版本尚未在这台电脑上完整执行四项安装及网络脚本；火绒的手动安装结果需要你在运行时确认。
